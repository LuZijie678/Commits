# Archive

这里存放历史运行产物、旧布局、旧预览源和已吸收后的数据轮次。

## 归档原则

- 主路径只保留当前有效入口
- 历史文件优先归档，不直接混在当前运行路径中
- 对数据轮次，只在确认“有效数据已吸收到正式层”后归档
- 如果某轮严格证明为空轮次，也可以归档，但不删除证据

## 当前目录

- `crawl_rounds/`: 已完成吸收确认的数据轮次
- `legacy_layout/`: 旧目录布局和旧入口说明
- `runs/`: 历史 Step1 / Step2 试跑产物
- `step2_preview_source/`: 已退役的 Step2 预览源

## 当前使用方式

- 这里不作为默认实验入口
- 需要追溯历史时再读取
- 当前默认入口以根目录 `README.md`、`code/`、`datasets/`、`docs/` 为准
